# Задача 1 «Матчинг товаров» — рабочая область darksteeld

> Рабочая область участника `darksteeld` (GitHub: DarkSteelD). Стадия:
> **предстартовое исследование завершено, код появится после пиновки данных и
> метрики со страницы задачи.** Исходные данные задачи читать из общей
> директории `../../data/raw/`; все производные артефакты — внутрь этой папки.

## Что здесь есть

Evidence base, собранная в мета-исследовании `ozon-ecup-2026` до открытия задач
(2026-08-09), перенесена в `reports/`:

- `FAMILY_MATCHING.md` — что двигает скор в product matching, с числами:
  Shopee Price Match, Amazon KDD Cup 2022 (ESCI), WDC Products, Ditto, R-SupCon,
  MWPD2020, Rakuten SIGIR-eCom.
- `00_SUMMARY.md` — сводный отчёт кампании по всем трекам и бейзлайнам.
- `PRIOR_EDITIONS.md` — метрики, масштабы данных и контейнерные envelope
  прошлых E-CUP (2024, 2025).
- `PUBLISHED_SOLUTIONS.md` — что из решений прошлых лет публично, что клонируемо,
  какие рецепты; включая `compute_score.py` организаторов матчинга-2024
  (per-category скоринг).
- `OZON_NATIVE.md` — схема данных матчинга-2024, продакшен-стек Ozon, выбор
  русскоязычного энкодера; три нерешённых противоречия.
- `FAMILY_RECSYS_TRANSFERABLE.md` — пять переносимых находок из recsys-треков.
- `CAMPAIGN_RULES.md` — процессные правила кампании (ship gate, oracle first,
  noise floor, prereg), оплаченные предыдущей трёхнедельной кампанией.

## Первые шаги после пиновки страницы задачи

1. Считать метрику, формат данных, наличие candidate pairs, контейнерный
   envelope — до этого не фиксировать архитектуру.
2. Оракульный потолок и noise floor LB до строительства первого лейна.
3. Кандидаты энкодеров и их лицензии — по `FAMILY_MATCHING.md` §лицензии и
   `OZON_NATIVE.md` §encoder choice; лицензию перепроверять при скачивании.

# RuModernBERT кросс-энкодер: воспроизведение

Всё, что нужно, чтобы получить нашу модель с нуля, плюс список того, что уже
проверено и не сработало — второе экономит столько же времени, сколько первое.

## Главное, что стоит знать до всего остального

**Локальная валидация у нас систематически расходится с лидербордом.** Два
измеренных случая, оба крупные:

| изменение | локально | на лидерборде |
| --- | ---: | ---: |
| обрезка предсказаний до 0/1 за порогами 0.05 и 0.95 | −0.0010 макро | **−0.0339** |
| претрен без дообучения против дообученной модели | **на 0.116 хуже** | **на 0.0057 лучше** |

Причина, судя по всему, в разной плотности дублей: в human_train их 25.7%, в
тесте около 11%, а по категориям расхождение доходит до восьмикратного. При
разногласии верить надо лидерборду.

## Результаты

Честный OOF, только на ручных парах, чтобы сравниваться с `ce_priodistill`:

| конфигурация | среднее по фолдам | макро по 20 категориям |
| --- | ---: | ---: |
| `ce_priodistill` (dzkhomidov, контроль) | 0.851713 | 0.799403 |
| ансамбль из 7 моделей (dzkhomidov, контроль) | 0.856377 | 0.804974 |
| rubert-base + LLM-претрен, AdamW, длина 224 | 0.855566 | 0.805135 |
| RuModernBERT, Adan 1e-4, длина 224 | 0.863304 | 0.813467 |
| **RuModernBERT, длина 320, обрезка атрибутов** | **0.864884** | **0.816898** |
| RuModernBERT, длина 1024, перестановка | 0.864319 | 0.816706 |

Публичный лидерборд:

| посылка | скор |
| --- | ---: |
| до нашей модели, лучшее у команды | 0.49693 |
| наша модель 224, одна | 0.50603 |
| **претрен 512 без дообучения** | **0.51169** |
| стек: модель 224 + student e3 len384 | **0.51245** |
| то же с обрезкой предсказаний | 0.47853 |

## Данные

    python ops/build_llm_texts.py --items data/raw/items.parquet --out llm_texts.parquet
    python src/build_distill_pairs.py --oof <all_model_predictions_oof.parquet> \
        --items data/raw/items.parquet --teacher final_stack_all --alpha 0.7 \
        --out hand_pairs_distill_aug.parquet

Претрен читает **простые** тексты `имя | категория | атрибуты`, дообучение —
**prio**: атрибуты переупорядочены по важности плюс блок
`@@ сравнение: цвет=...; артикул=...`. Имя обрезается по первому `' | '` —
дефект `run_v4` у dzkhomidov, воспроизведён намеренно, потому что так делает
инференс.

## Шаг 1: претрен на разметке LLM

Цель — та же «дубль/не дубль», но метка мягкая: доля голосов LLM за дубль,
десять уровней с шагом 1/9.

    python ops/pretrain_llm.py --texts llm_texts.parquet --pairs matches_llm.parquet \
        --model deepvk/RuModernBERT-base --num-labels 1 --out ckpt/mb_llm_512 \
        --epochs 1 --max-len 512 --bs 32 --workers 16 --lr 5e-5 \
        --compile --pad-multiple 64 --length-buckets --swap-augment --save-every 2000

16 часов на RTX 5070 Ti при 191 пар/с.

**Длина претрена решает больше, чем кажется.** Замер на 20 тысячах ручных пар,
все претрены честны по построению — ручных меток они не видели:

| претрен | вход | PR-AUC |
| --- | ---: | ---: |
| RuModernBERT, претрен 160 | 160 | 0.733139 |
| RuModernBERT, претрен 160 | 512 | **0.714784** |
| RuModernBERT, претрен 512 | 512 | **0.748740** |
| rubert-base, претрен 160 | 384 | 0.744386 |
| rubert-base, претрен dzkhomidov | 384 | 0.735291 |

Вторая строка — суть дела: дайте короткому претрену длинный вход, и станет
**хуже**. Модель не умеет пользоваться контекстом, которого не видела. Отсюда и
насыщение длины при дообучении: 224 → 320 давало +0.0023, а 320 → 1024 ничего.

## Шаг 2: дообучение по фолдам

    python ops/train_distill.py --data hand_pairs_distill_aug.parquet \
        --model deepvk/RuModernBERT-base --init ckpt/mb_llm_512 --num-labels 1 \
        --out runs/ce1 --stage folds --epochs 1 --bs 24 --eval-bs 24 \
        --max-len 512 --workers 16 --optimizer adan --lr 1e-4 --compile \
        --pad-multiple 64 --drop-closure --length-buckets --duplicate-swapped \
        --save-models

`--drop-closure` обязателен: выведенные транзитивным замыканием пары измеренно
вредят, −0.001594 на всех фолдах.

Если стартовать с чекпоинта на две головы при `--num-labels 1`, голова не
переинициализуется, а сворачивается: скор всегда считался как `logit1 - logit0`,
и один логит с весами `W1 - W0` вычисляет ровно ту же функцию.

## Шаг 3: второй этап на ошибках

    python ops/train_distill.py ... --init runs/ce1/model_<fold> --folds <fold> \
        --lr 3e-5 --error-weights runs/ce1_oof.parquet --error-alpha 2.0

Вес примера — `1 + alpha * |target - score|`, где score берётся **из OOF первого
этапа**, то есть от модели, которая этой пары не видела. По подогнанным ответам
считать нельзя: усилились бы не трудные примеры, а запомненные.

## Шаг 4: усреднение весов фолдовых моделей

    python ops/soup_models.py --models runs/ce1/model_fold_0{1,2,3,4} --out runs/soup

Законно, потому что все стартовали из одной точки вместе с головой и разошлись
мало (скрипт печатает величину). **Качество супа локально не проверяется:**
модели вместе покрывают все фолды, любая оценка внутривыборочна. У нас выходило
0.908 против честных 0.863.

## Скорость

| приём | эффект |
| --- | --- |
| `--compile --pad-multiple` | +59% на претрене, +48% на фолдах |
| `--length-buckets` | −38% вычислений на добивку пустыми токенами |
| `GradScaler` отключён | при bf16 бесполезен, стоит синхронизации на каждом шаге |
| `--compile-mode reduce-overhead` | **хуже на 11%** |
| `mode=max-autotune` | **хуже втрое** |

`torch.compile` может не собраться из-за отсутствия заголовков python3.12:
Triton компилирует C-расширение с `#include <Python.h>`, а сообщение об ошибке
при этом указывает на `libcuda` и уводит в сторону. Без прав root:

    apt-get download libpython3.12-dev python3.12-dev
    dpkg-deb -x <файл>.deb ~/pyinc
    export CPATH=$HOME/pyinc/usr/include/python3.12:$HOME/pyinc/usr/include

## Что проверено и не сработало

- **Обрезка хвостов атрибутов вместо конца пары.** Блок сравнения при обычной
  обрезке выживает лишь в 7.5% обрезанных пар, адаптивная сохраняет его в 100% —
  и всё равно хуже на 0.00076, устойчиво на 4 фолдах из 4.
- **Длина сверх 320.** На 1024 обрезки нет вовсе, разницы с 320 нет тоже.
- **Пары из транзитивного замыкания в обучении** — −0.001594.
- **Доразметка спорных пар** — три независимых измерения, все в пределах шума.
- **Обрезка предсказаний до 0/1** — на лидерборде −0.0339.
- **Третья модель в стеке** — +0.000252 сверх лучшей пары, ниже шумового пола.
